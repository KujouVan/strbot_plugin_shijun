# 识君 2.1.0

自动沿用当前会话在 AstrBot 中选择的人格、性格和提示词。无需把人格复制到插件，修改人格后后续请求自然使用新设置。

## 使用

1. 在 AstrBot「人格设置」中编辑角色与文风，并为会话选择人格。
2. 插件页 → 识君 → 打开视图，按真实发送者 QQ 配置关系、称呼和可选专属要求。
3. 默认沿用人格，仅显式填写的关系、称呼和专属要求覆盖冲突部分。专属文风优先模式需要填写专属要求，未指定部分仍沿用人格。
4. 预览仅显示识君的人物补充，不展示当前会话的完整人格；保存后后续请求生效。

未命中人物或插件关闭时，不追加任何提示词。人格由 AstrBot 正常请求链路提供，识君不另行读取默认人格，因此支持不同会话选择不同人格。插件不增加模型调用，不更改图片、工具或历史字段。

## 从 2.0.x 升级

删除内置简短毒舌提示词和全局文风编辑框。旧配置中的 `style_prompt` 不再使用，保存时移除；不会自动复制旧文风到人格。既有 QQ 人物关系和专属要求保留。`inherit` / `replace` 模式仍兼容，均不清除人格中的身份、事实和工具规则。

强化模式可在当前消息末尾补充人物提醒，标准模式仅追加系统补充。提醒可能随框架请求存入历史；旧历史中的提示不自动清除。关闭插件只影响后续请求。

QQ 匹配主要适用于 aiocqhttp / OneBot；官方 QQ 非数字 OpenID 无法匹配数字 QQ。群聊与私聊共用人物配置，不以昵称、正文、引用或 @ 的号码判断发言者。关系不会授予管理或工具权限。

配置通过 AstrBot 后台鉴权桥接保存，带版本冲突检查。模型实际遵循程度以回复为准。

## 本版本验证

运行 `python -m unittest discover -s tests -v` 检查人格透传、会话切换、旧全局文风忽略、人物匹配、重复注入及关闭清理。云端实际部署与 QQ 回复需在目标实例另行验证。
