# 识君 3.0

按真实发送者 QQ 选择完整人格，同一人在私聊和群聊使用同一配置。

- 融合修改人格：选择基础人格，填写修改要求、关系和称呼，生成融合草稿。可以直接编辑生成结果；保存后下一次聊天使用该完整人格。修改输入后必须重新生成。基础人格之后变化不会自动覆盖结果。
- 完全替换人格：所填正文就是完整人格，不补入原人格。关系与称呼若填写，会成为新人格的明确字段。
- 未匹配或停用：使用原会话人格。

替换框架的 Persona Instructions 部分，保留工具权限、其他插件上下文和真实对话历史，移除旧人格的开场示例。不追加优先级提醒，不改写用户消息。旧聊天历史仍可能影响表达。

融合生成调用一次默认聊天模型，失败不保存；预览不会调用模型。保存包含版本检查，防止覆盖其他页面的修改。边界无法识别时跳过本次替换并记日志，避免误删工具和记忆。
